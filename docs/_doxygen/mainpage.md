# ADS9324 Driver API reference {#mainpage}

The classes, types and registers of the ADS9324 driver, generated from the headers in `inc/`.

Start with ads9324::ADS9324, the driver, and ads9324::SpiInterface, the base of the port you write. Errors are
ads9324::Error inside ads9324::Result; the configuration is ads9324::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">ADS9324 Driver
documentation</a>.
