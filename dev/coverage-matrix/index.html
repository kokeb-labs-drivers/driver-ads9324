Coverage matrix¶

One row for each parameter, register field, mode, pin and timing the data sheet specifies. The API column names the symbol of this driver that covers the row. tools/check_matrix.py (part of tools/preflight.sh) fails when a symbol cited here is not in inc/, src/ or docs/hardware.yml (a symbol that appears only in a comment does not count), when a test id does not start the name of a TEST_CASE in tests/, when a row is malformed, or when the counts below are wrong. The Test column names a topic: every test case whose name starts with that id belongs to it, so the table shows where a row is tested, not which assertion proves it. A row the driver does not cover has the status GAP and says so in the API column.

Status: OK covered and tested, GUARD the driver restricts the values to the documented ones, TODO the data sheet leaves it open or the feature is out of scope for this version, INFO a fact with no driver behaviour, GAP the data sheet value has no symbol in the driver.
