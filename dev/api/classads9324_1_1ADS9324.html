Detailed Description

template<SpiPort Port>
class ads9324::ADS9324< Port >

Driver for one ADS9324 on a platform port.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized(), the one way to start (bus up, power-up wait, reset, identity check, configuration), use, optionally Deinitialize(). Every call that touches the chip returns Error::NotInitialized until EnsureInitialized() has succeeded; no call starts the chip as a side effect.

Configuration is written through a write-through shadow of every register: a call writes only the registers that differ from what the chip holds, and a setter stores the new configuration only after the chip accepted it. Setters take a trailing Verify that reads every register back.

Optional port hooks, found at compile time:

  • bool GpioSet(CtrlPin, GpioSignal) noexcept drives the RESET pin and the CONVST pulse. Without it Convert() and a hardware reset return Unsupported, and so does single-shot calibration.
  • bool GpioGet(CtrlPin, bool& high) noexcept reads the DRDY/ALARM pin. Without it ReadySource::Pin waits and ReadAlarmPin() return Unsupported.
  • bool CaptureLanes(uint8_t lanes, uint8_t* rx, std::size_t len) noexcept reads data on D7 to D0. Without it frames on D7 to D0 return Unsupported; one lane on SDOUT works.
  • void Log(LogLevel, const char* message) noexcept takes one line per lifecycle event or failure. Without it nothing is logged.

void DelayUs(uint32_t us) noexcept is required. A hook declared with the wrong signature is a compile error.

◆ EnsureInitialized()

template<SpiPort Port>
Result< void > ads9324::ADS9324< Port >::EnsureInitialized ( )
noexcept

Start the chip, once: the only way to initialise the driver.

Brings the port up, waits the 30 ms power-up time, resets the chip (the RESET pin when Config::hardware_reset is set, else SW_RST), reads DEVICE_ID and BANK_SEL, waits for CALIB_BUSY to clear, clears RESET_DETECT_FLAG, writes the configuration and optionally runs the ADC calibration. After it succeeds, later calls return Ok at once with no I/O. After it fails, the next call starts again from the beginning.

Returns
Ok, InvalidArgument (the configuration fails Validate(); no I/O), Unsupported (daisy chain, or a hardware reset without GpioSet()), Bus, Timeout, DeviceIdMismatch, VerifyFailed or the calibration errors.

◆ RunAdcCalibration()

template<SpiPort Port>
Result< void > ads9324::ADS9324< Port >::RunAdcCalibration ( )
noexcept

Run the ADC calibration with Config::calibration.

Single shot: INT_TRIG_MODE, ADC_CAL_MODE, TRIG 0 to 1 and back, one CONVST pulse ending high, then at most 125 ms plus 25 ms of CALIB_BUSY polling. Continuous: expects a free-running CONVST and waits 100,000 periods. ADC_CAL_MODE stays set afterwards (mode 0 would remove the calibration).

Returns
Ok, NotInitialized, Refused (powered down, or a digital filter is on), Unsupported (single shot without GpioSet()), Timeout or Bus.
