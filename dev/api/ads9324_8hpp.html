Detailed Description

ADS9324 driver: the one header to include.

Copyright

ads9324::ADS9324<Port> drives one ADS9324 16-channel, 16-bit, 1 MSPS simultaneous-sampling ADC through a platform port you write (see ads9324_spi_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.

Channels are counted from 0: channel 0 is AIN1 and channel 15 is AIN16. Results are signed codes and integer microvolts; there is no floating point.
