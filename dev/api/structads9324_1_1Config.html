Detailed Description

Everything EnsureInitialized() and ApplyConfig() write to the chip.

Config{} is the datasheet's initialisation example (Table 7-18: 16-bit words on SDOUT, one lane) over the reset values of every other register; ChipResetConfig() is the chip's reset state, eight lanes on D7 to D0.
