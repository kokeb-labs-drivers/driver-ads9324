Detailed Description

Public types of the ADS9324 driver: errors, Result<T>, enumerations, configuration, the data frame and the pure helpers that decode it.

Copyright
Copyright (c) 2026 The driver-ads9324 authors. SPDX-License-Identifier: MIT

Everything here is plain data and constexpr code with no platform dependency, so tests and tools can include it without the driver template. Channels are counted from 0: channel 0 is AIN1 and channel 15 is AIN16. Voltages are integer microvolts; the driver has no floating point.
