Detailed Description

template<typename Derived>
class ads9324::SpiInterface< Derived >

CRTP base of the platform port.

Derive class MyPort : public ads9324::SpiInterface<MyPort> and implement the hooks in this file's description. The base declares no hook itself (a forwarding hook would turn a missing override into infinite recursion) and no data; the driver checks your class with the SpiPort concept, so a missing or misdeclared hook is a compile error that names it.
