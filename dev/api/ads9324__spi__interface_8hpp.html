Detailed Description

The port of the ADS9324 driver: the CRTP base, its pin enums, the SpiPort concept and the 24-bit register framing.

The driver never calls an SDK. It calls hooks on a class you derive from ads9324::SpiInterface<Self>:

  • bool EnsureInitialized() noexcept brings the bus and pins up on the first call; true at once afterwards.
  • bool Transfer(const uint8_t* tx, uint8_t* rx, std::size_t len) noexcept is one full-duplex transfer with CS low for all len bytes; rx may be nullptr.
  • void DelayUs(uint32_t us) noexcept waits at least us microseconds.

The port moves raw bytes: it never retries, never interprets a frame and never configures the chip. What the chip needs from the bus is below as constexpr values (kSpiMode to kFrameBits, datasheet sections 5.6, 5.7 and 7.5); a port checks its settings against them with static_assert. The optional hooks (GpioSet, GpioGet, CaptureLanes, Log) are described in ads9324.hpp.
