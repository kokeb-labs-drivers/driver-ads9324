◆ kContinuousWord

constexpr bool ads9324::kContinuousWord = false
inlineconstexpr

false: SCLK may pause between bytes of a frame, so a port need not send a whole frame without gaps (the chip decodes on the rising edge of CS, not on a byte count).

◆ kFrameIsAtomic

constexpr bool ads9324::kFrameIsAtomic = true
inlineconstexpr

true: CS stays low for a whole frame; the chip decodes a frame when CS rises (section 7.5).

◆ kMaxSdoutClockHz

constexpr uint32_t ads9324::kMaxSdoutClockHz = 29'000'000
inlineconstexpr

Highest SCLK frequency when SDOUT is read in mode 0: the 17 ns td_CKDO must fit half a period (assumption A2). A port that reads registers or data checks against this one.

◆ kSpiMode

constexpr uint8_t ads9324::kSpiMode = 0
inlineconstexpr

SPI mode the driver is tested with: CPOL 0, CPHA 0. The datasheet names none (assumption A1, derived from the timing diagram: SDI is sampled on the rising edge).
